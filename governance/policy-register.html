1. Purpose

The Master Policy Register is the single source of truth for all compliance, security, and governance documentation maintained by Ramdoot Solutions. It provides a complete inventory of every policy, procedure, register, and report in the compliance documentation suite, along with ownership, approval status, versioning, review schedules, and document locations.

This register supports the Compliance Policy (RS-GOV-002) requirement for policy lifecycle management and ensures that all documentation is current, reviewed on schedule, and owned by the appropriate parties. It also serves as a readiness reference for SOC 2/SOC 1 audits, enabling auditors to quickly locate relevant documentation.

2. How to Use This Register

Instructions for Document Owners and the Compliance Officer:

  1. New Documents: When a new policy, procedure, register, or report is created, add it to this register immediately. Assign a unique Document ID following the naming convention (see Section 3).
  2. Status Tracking: Update the Status column as documents progress through their lifecycle (Draft, Under Review, Approved, Retired).
  3. Review Scheduling: Set the Next Review Date based on the review frequency for the document type. The Compliance Officer is responsible for initiating reviews before the due date.
  4. Version Updates: When a document is revised, update the Version and Effective Date in this register.
  5. Retirement: When a document is superseded or no longer applicable, update its status to Retired and note the replacement document if applicable.
  6. Audit Preparation: Before any audit, review this register to confirm all documents are current, approved, and accessible at their listed locations.

4. Document Status Definitions

Status Description
Draft Document created but not yet reviewed or approved. May be incomplete.
Under Review Document is undergoing review by designated reviewers or approvers.
Approved Document reviewed, approved, and in effect. This is the authoritative version.
Retired Document is no longer in effect. Superseded by a newer version or no longer applicable.
